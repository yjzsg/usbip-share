# 运行时数据目录

compose 会把宿主机的 `./config` 挂载到容器内的 `/etc/usbip`，因此**本目录必须可写**，
且容器重建、迁移目录时应整目录保留。首次启动后这里会出现：

| 文件 | 内容 | 丢了会怎样 |
|---|---|---|
| `auth.json` | 管理密码的盐与散列（PBKDF2-SHA256）、是否仍需修改默认密码 | 回到默认密码 `123456`，需重新设置 |
| `device-metadata.json` | 设备名称与备注（按硬件身份保存） | 设备名回到"未设置"，需重新命名 |
| `device-metadata.json.bak` | 服务端自动维护元数据前的备份 | 无影响，可删 |

**不要把这些文件提交到 Git**（仓库根的 `.gitignore` 已排除本目录，只保留本说明文件）。
